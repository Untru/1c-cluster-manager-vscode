# 1C Cluster Manager

Нативное расширение VS Code для управления кластерами 1С:Предприятия через RAS/rac.

## Использование

1. Убедитесь, что RAS запущен, а `rac` установлен на компьютере, где работает Extension Host VS Code.
2. Откройте панель «Кластеры 1С».
3. Добавьте подключение, например `localhost:1545`.
4. Раскройте кластер или выберите коллекцию, чтобы открыть её таблицу в центральной области.

При недостаточных правах расширение само запрашивает логин и пароль администратора, сохраняет их только через защищённое `SecretStorage` VS Code и повторяет операцию. Встроенный backend запускается локально автоматически.

Через контекстное меню списка информационных баз можно зарегистрировать новую базу без создания физической БД, удалить только регистрацию, включить/выключить блокировки сеансов и регламентных заданий, а также разрешить или запретить выдачу лицензий сервером 1С. Команда «Показать подробности» получает полные свойства базы.

Щелчок по информационной базе открывает редактируемую карточку её свойств. Сама база раскрывается в отдельные сеансы, соединения, блокировки и, если поддерживается версией платформы, хранилища двоичных данных.

Все коллекции открываются таблицами с поиском, обновлением и CSV-экспортом. Таблица сеансов поддерживает групповой выбор и завершение. Рабочий процесс открывается карточкой статистики, рабочий сервер — редактируемой карточкой параметров. Требования назначения и настройки сервисов находятся внутри соответствующего рабочего сервера.

Расширение определяет возможности из справки конкретного `rac`: разделы `service-setting` и `binary-data-storage` появляются только в версиях, где утилита их предоставляет.
