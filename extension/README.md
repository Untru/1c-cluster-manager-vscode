# 1C Cluster Manager

Нативное расширение VS Code для управления кластерами 1С:Предприятия через RAS/rac.

## Использование

1. Убедитесь, что RAS запущен, а `rac` установлен на компьютере, где работает Extension Host VS Code.
2. Откройте панель «Кластеры 1С».
3. Добавьте подключение, например `localhost:1545`.
4. Если в кластере настроен администратор, вызовите контекстную команду «Указать администратора кластера».
5. Для административных операций информационной базы при необходимости отдельно укажите её администратора.

При недостаточных правах расширение само запрашивает логин и пароль администратора, сохраняет их только через защищённое `SecretStorage` VS Code и повторяет операцию. Встроенный backend запускается локально автоматически.

Через контекстное меню списка информационных баз можно зарегистрировать новую базу без создания физической БД, удалить только регистрацию, включить/выключить блокировки сеансов и регламентных заданий, а также разрешить или запретить выдачу лицензий сервером 1С. Команда «Показать подробности» получает полные свойства базы.

Щелчок по информационной базе открывает редактируемую карточку её свойств. Узел «Сеансы» открывает таблицу с поиском, экспортом CSV, групповым выбором и завершением выбранных сеансов.
Узел «Блокировки» открывает в центральной области таблицу блокировок с поиском, обновлением и экспортом CSV.
