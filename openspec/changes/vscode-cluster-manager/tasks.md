# Управление кластерами 1С из VS Code — план реализации

**Цель:** реализовать самостоятельные backend и расширение VS Code для управления кластерами 1С через RAS/rac.

**Дизайн:** `openspec/changes/vscode-cluster-manager/design.md`

## Задача 1: Каркас проекта и контракты

**Статус:** `[x]`

- Создать npm workspaces, общие настройки TypeScript и документацию дизайна.
- Зафиксировать API, модель подключений и критерии безопасности.

## Задача 2: Backend и адаптер rac

**Статус:** `[x]`

- Реализовать поиск `rac`, безопасный запуск без shell, парсер вывода и конфигурационное хранилище.
- Реализовать REST API чтения ресурсов и административных команд.
- Добавить unit- и интеграционные тесты.

## Задача 3: Расширение VS Code

**Статус:** `[x]`

- Реализовать API-клиент, хранение секретов и дерево ресурсов.
- Реализовать команды подключения, авторизации, обновления и управления кластером.
- Добавить тесты независимой логики представления.

## Задача 4: Сборка и сквозная проверка

**Статус:** `[x]`

- Собрать оба workspace и выполнить тесты.
- Запустить backend и проверить получение кластеров из локального RAS.
- Собрать устанавливаемый VSIX.

## Задача 5: Документация

**Статус:** `[x]`

- Описать запуск backend, установку VSIX, подключение и модель безопасности.
- Проверить критерии приёмки из дизайна.
