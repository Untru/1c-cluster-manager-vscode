# Управление кластерами 1С из VS Code — дизайн

## Цель

Создать независимое решение для администрирования кластеров 1С из VS Code. Решение не использует backend, JAR, конфигурацию или внутренние API «ПУСК».

## Архитектура

- `backend` — локальный HTTP-сервис на Node.js/TypeScript. Он хранит только параметры подключений, автоматически находит `rac`, запускает его без shell и преобразует текстовый вывод в JSON.
- `extension` — расширение VS Code на TypeScript. Оно отображает подключения, кластеры и ресурсы через `TreeDataProvider`, вызывает backend и хранит пароли только в `SecretStorage` VS Code.
- `RAS/rac` — штатный интерфейс администрирования платформы 1С. Backend не подключается к «ПУСК» и не читает его файлы.

## Функциональность MVP

1. Добавление и удаление подключений к RAS.
2. Автопоиск установленного `rac.exe` и возможность указать путь явно.
3. Просмотр кластеров, информационных баз, сеансов, соединений, блокировок, рабочих серверов, процессов, менеджеров и сервисов.
4. Хранение учётных данных администратора кластера и информационной базы в `SecretStorage`.
5. Завершение сеанса, прерывание серверного вызова, разрыв соединения и выключение рабочего процесса.
6. Включение и выключение блокировки сеансов и регламентных заданий информационной базы.
7. Подтверждение разрушающих операций, таймауты, ограничение размера вывода и маскирование секретов.

## API

- `GET /health`
- CRUD `/api/connections`
- `GET /api/connections/:connectionId/clusters`
- `GET /api/connections/:connectionId/clusters/:clusterId/{infobases|sessions|connections|locks|servers|processes|managers|services}`
- команды над сеансами, соединениями, процессами и настройками информационных баз через `POST`.

Учётные данные передаются расширением в заголовках только на время запроса. Backend их не сохраняет. По умолчанию backend слушает только `127.0.0.1`; для дополнительной защиты поддерживается bearer token.

## Критерии приёмки

- Оба пакета компилируются в строгом TypeScript-режиме.
- Unit-тесты парсинга `rac`, построения команд и HTTP API проходят.
- Backend получает реальные кластеры через найденный локальный `rac.exe`.
- Расширение содержит нативное дерево и команды управления, а не WebView со страницей «ПУСК».
- В исходном коде отсутствуют обращения к `localhost:8080` и артефактам «ПУСК».
